# PR specs

The spec written for each pull request before any code: what to build, what to check, and what
"done" means. An AI coding agent implemented each one, showed its plan first, and every PR was
reviewed and tested by hand before merging.

Files are named `prNN-<short-name>.md` after the PR's number in the build plan (`pr09a-…` and
`pr09b-…` for a PR split in two). That number is the plan's, not GitHub's: GitHub's #4 is the
plan's PR 5.
